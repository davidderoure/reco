KEY CHANGES FROM V1:
--------------------
✓ Removed mood tracking (will be used for evaluation only)
✓ Changed from single theme to multiple tags per story

✓ Added story_progress event (completion percentage 0-100)
✓ Changed favorites to bookmarks (moderate preference signal)
✓ Implemented ignore decay for repeatedly skipped stories
✓ Added configurable recommendation slots (2-2-1-1 default)
✓ Added recommendation provenance (method + slot position)
✓ Updated all 25 Oxford stories with tag-based organization
✓ Added state export with date filtering
✓ Created gRPC interface for C# mobile app
